# Portfolio assets

Replace these placeholders with your own files while keeping the filenames used by `index.html`:

- `profile.jpg` - professional portrait
- `project1.jpg`, `project2.jpg`, `project3.jpg` - project screenshots
- `certificate1.jpg` - certificate image, if needed for future links
- `resume.pdf` - downloadable résumé

The layout hides missing images gracefully until real assets are added.
